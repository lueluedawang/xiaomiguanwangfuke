# 小米官网复刻

一个纯前端的小米官网（mi.com）复刻练习项目，使用原生 HTML + CSS + JavaScript 实现，无框架、无构建工具，开箱即用。

> 本项目仅用于学习交流，非小米官方站点，与小米公司无任何关联。

## 功能特性

- **首页**：全宽轮播图（自动播放 + 左右箭头 + 圆点切换）、导航悬停 Mega Menu 下拉面板、快捷入口、限时倒计时、明星单品横幅、精选产品网格
- **小米商城**：左侧分类切换、商品动态渲染、关键词搜索
- **登录 / 注册**：弹窗式表单、登录态校验、密码可见切换（localStorage 持久化登录状态）
- **购物车**：加购、数量增减、删除、合计结算（localStorage 持久化，刷新不丢失）
- **子页面**：澎湃OS、小米汽车、小米影像、云服务、IoT 平台、小米有品（秒杀倒计时 / 众筹 / 新品推荐）
- **其他**：图片放大镜、返回顶部、加载动画、768px 响应式适配

## 技术栈

- HTML5 / CSS3（Flexbox / Grid / 粘性导航 / 媒体查询）
- 原生 JavaScript（DOM 操作、localStorage、定时器、事件委托）

## 快速开始

无需安装任何依赖，两种方式任选：

```bash
# 方式一：直接双击 index.html 打开

# 方式二：本地静态服务器（推荐）
py -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 文件结构

```
├── index.html   # 全部页面结构（单页切换）
├── style.css    # 全部样式
└── script.js    # 全部交互逻辑
```
